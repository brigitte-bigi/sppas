    Class bidict

    Description

    A simple bidirectional dictionary.

    Implements a 1:1 dictionary. It implies that two keys can't have the same value.

    Example
     >>> relation = bidict()
 >>> relation['Alice'] = 'Bob'
 >>> print(relation['Bob'])
 >>> 'Alice'
 >>> print(relation['Alice'])
 >>> 'Bob'
