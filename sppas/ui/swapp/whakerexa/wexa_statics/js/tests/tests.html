Unit tests

Open the console of the browser: every assertion writes there, in green when it succeeds and in red when it fails.

This page has to be served over http. Opened as a file:// document, the browser refuses to load the modules, and nothing runs. From the root of the repository:

python3 -m http.server 8000

then open http://localhost:8000/wexa_statics/js/tests/tests.html.

What is tested

  • Book, the table of contents
  • Author
  • Link
  • Reference
  • BibtexParser
  • ReferenceFormatter
  • BibliographyTable, and CitedReference with it
  • BibtexSource, which reads sample.bib
  • ReferenceDisclosure
  • BibliographyControls
  • CitedKey and Citation
  • CitationIndex
  • BookBibliography

Of the slides, what is laid out on a paginated support:

  • SlideBlock
  • SlideLayout
  • SlidePaginator, which needs no rendering
  • SlideBlockReader

Of what customises the look, which set of icons answers a name:

  • IconSet
  • IconSets, which reads nothing and asks nothing
  • IconChoice
  • IconReader, which goes and gets as rarely as it can
  • IconDemand and IconPlacer
  • IconRegister
  • IconManager, which never raises
